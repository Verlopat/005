 PhD Phase 1: Reference Links & Resources

1. THE DATASET (CICIoT2023)
   -------------------------
   We used the HuggingFace streaming dataset for the CICIoT2023 network traffic.
   URL: https://huggingface.co/datasets/lacg030175/CIC-IoT-2023-full
   Info: This dataset contains the 46 features and the 34 attack types that we mapped down to binary Benign/Attack.

2. THE ARCHITECTURE COMPONENTS (STAHN)
   -------------------------
   Our STAHN (Squeeze-and-Excitation Temporal Attention Hybrid Network) is based on the following mathematical concepts:
   - PyTorch TransformerEncoder (Self-Attention): https://pytorch.org/docs/stable/generated/torch.nn.TransformerEncoder.html
   - "Attention Is All You Need" (Original Transformer Paper): https://arxiv.org/abs/1706.03762
   - Squeeze-and-Excitation Networks (The SEBlock feature-weighing logic): https://arxiv.org/abs/1709.01507
   - PyTorch Bidirectional LSTM: https://pytorch.org/docs/stable/generated/torch.nn.LSTM.html

3. PREPROCESSING LOGIC
   -------------------------
   - Scikit-Learn StandardScaler (For chunk-by-chunk scaling): https://scikit-learn.org/stable/modules/generated/sklearn.preprocessing.StandardScaler.html
   - Imbalanced-Learn SMOTE (Synthetic Minority Over-sampling to fix Class Imbalance): https://imbalanced-learn.org/stable/references/generated/imblearn.over_sampling.SMOTE.html
